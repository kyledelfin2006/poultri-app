# Poultri

Poultri is a proposed low-cost early-warning monitoring system for layer farms. This repository contains the mobile demonstrator in [`mobile/`](mobile/).

The prototype uses local simulated readings and records to demonstrate the planned farmer experience. It does not diagnose and does not connect to real cameras or sensors.
